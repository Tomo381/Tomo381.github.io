# Tomoya Portfolio

**公開URL:** https://tomo381.github.io/

UI/UXデザインとWeb開発を中心に活動する、友哉のポートフォリオサイトです。

---

## 📄 ページ構成

| ページ | ファイル | 内容 |
|---|---|---|
| Home | `index.html` | ヒーローセクション・制作物一覧・Contact |
| About | `about.html` | プロフィール・趣味・活動歴 |
| Skills | `skills.html` | 使用技術・スキル一覧 |

---

## 🛠️ 技術スタック

- HTML / CSS / JavaScript（フレームワーク不使用）
- `IntersectionObserver` によるスクロールフェードインアニメーション
- CSS変数によるデザインシステム（紺色 `#0d274d` 基調）
- レスポンシブ対応（モバイル・タブレット・PC）

---

## 📂 ディレクトリ構成

```
tomo381.github.io/
├── index.html      # Home（制作物一覧・Contact）
├── about.html      # About（プロフィール・活動歴）
├── skills.html     # Skills（技術スタック）
├── style.css       # 共通スタイル
├── script.js       # スクロールアニメーション
└── images/
    ├── hero-bg.jpg       # ヒーロー背景画像
    ├── profile.jpg       # プロフィール写真
    ├── work-piano.png    # 制作物A サムネイル
    ├── work-map.png      # 制作物B サムネイル
    └── work-nagoya.png   # 制作物C サムネイル
```

> `images/` 内の画像は差し替え可能です。ファイル名を合わせて配置してください。
